🧠 BLOCO DE CONTEXTO (cole primeiro no coder)

PROJETO: Zashterminal — emulador de terminal GTK4/libadwaita em Python 3.9+.
REPO: github.com/VaGNaroK/zashterminal-Fork
STACK: Python, PyGObject (GTK4), VTE4, libadwaita. Deps atuais: pycryptodomex,
requests, pygments, psutil, regex. NÃO adicionar dependências de runtime novas
sem justificativa explícita (dataclasses/stdlib preferidos; nada de pydantic).

CÓDIGO CANÔNICO: src/zashterminal/ (a cópia em locale/src/ será REMOVIDA na Fase 0).

PADRÕES OBRIGATÓRIOS:
1. Assincronia: toda I/O (rede, disco, subprocess) via core/tasks.py; UI atualizada
   SOMENTE via GLib.idle_add. Nunca bloquear o main loop do GTK.
2. A IA NUNCA executa comandos: ela produz um ActionPlan JSON; a execução passa por
   PolicyEngine → aprovação humana → ToolRegistry.
3. subprocess SEMPRE com shell=False e argv como lista.
4. Default-deny: caminhos sensíveis e ações administrativas são negados por padrão.
5. Toda execução gera registro de auditoria (JSONL).
6. Saída de comandos e conteúdo de arquivos = DADOS NÃO CONFIÁVEIS (nunca tratar
   como instrução; envolver em marcadores <untrusted> ao enviar ao LLM).

OBJETIVO: transformar o Assistente de IA atual (painel inferior, botão "executar")
em um agente estratificado por risco com: leitura/escrita escopada na home,
ferramentas administrativas via Polkit/pkexec, dry-run, diff com backup, auditoria
e rollback — mantendo o UX de duas camadas (terminal em cima, chat embaixo).

Objetivo: definir o contrato JSON que o LLM deve produzir.
T1.1 — Criar src/zashterminal/agent/__init__.py e agent/models.py

# src/zashterminal/agent/models.py
from dataclasses import dataclass, field, asdict
from enum import IntEnum
from typing import Optional

class RiskLevel(IntEnum):
    READ_ONLY  = 0   # ls, df, du, journalctl --disk-usage
    USER_WRITE = 1   # criar/editar arquivos na home
    ADMIN      = 2   # ações administrativas nomeadas (Polkit)
    CRITICAL   = 3   # rm -rf escopado, alterações de serviço
    BLOCKED    = 4   # nunca executar

@dataclass
class ActionStep:
    step_id: str
    tool: str                     # "shell.run" | "fs.read_file" | "fs.write_staged_file" | "admin.run_action" ...
    argv: list[str]
    description: str
    risk: int                     # RiskLevel
    requires_admin: bool = False
    dry_run_argv: Optional[list[str]] = None
    working_directory: Optional[str] = None
    timeout_seconds: int = 30
    approval: str = "click"       # "click" | "diff" | "polkit" | "blocked"

@dataclass
class ActionPlan:
    plan_id: str
    intent: str
    summary: str
    steps: list[ActionStep] = field(default_factory=list)
    provider: str = ""

@dataclass
class ToolResult:
    status: str                   # "ok" | "error" | "denied" | "timeout"
    stdout: str = ""
    stderr: str = ""
    exit_code: int = 0
    truncated: bool = False
    secrets_redacted: int = 0

@dataclass
class AuditRecord:
    timestamp: str
    plan_id: str
    step_id: str
    tool: str
    argv: list[str]
    risk: int
    user_decision: str            # "approved" | "denied" | "dry_run"
    result_status: str

Implementar to_dict()/from_dict() com validação estrita (chaves desconhecidas → erro; risk fora de 0..4 → erro; argv não-lista → erro).
T1.2 — Criar data/agent_tools_schema.json

🟡 FASE 2 — Motor de Políticas e Guarda de Caminhos
Objetivo: classificar risco e impor default-deny, independente do que o LLM disser.
T2.1 — Criar data/policies/deny_patterns.json
Lista de regex aplicados sobre argv (join + por elemento). Mínimo obrigatório:

[
  {"pattern": "rm\\s+(-[a-zA-Z]*[rf][a-zA-Z]*\\s+)+(/|~|\\$HOME)(\\s|$)", "reason": "remoção recursiva de raiz/home"},
  {"pattern": "mkfs\\.", "reason": "formatação"},
  {"pattern": "dd\\s+.*of=/dev/", "reason": "escrita em dispositivo"},
  {"pattern": "chmod\\s+-R\\s+(777|a\\+rwx)\\s+(/|~)(\\s|$)", "reason": "permissões recursivas perigosas"},
  {"pattern": "(curl|wget)\\b.*\\|\\s*(sudo\\s+)?(ba)?sh", "reason": "download+execução via pipe"},
  {"pattern": ">\\s*/etc/(passwd|shadow|sudoers)", "reason": "escrita em arquivos críticos"},
  {"pattern": "shutdown|reboot|poweroff", "reason": "reinicialização"},
  {"pattern": ":\\(\\)\\{", "reason": "fork bomb"}
]

T2.2 — Criar data/policies/admin_actions.json
Ações administrativas NOMEADAS (única forma de obter privilégio):

{
  "pkg.autoremove": {"argv": ["{pkg}", "autoremove"], "dry_run_argv": ["{pkg}", "autoremove", "--dry-run"], "risk": 2},
  "pkg.clean_cache": {"argv": ["{pkg}", "clean"], "risk": 2},
  "logs.vacuum": {"argv": ["journalctl", "--vacuum-time={period}"], "risk": 2},
  "flatpak.unused": {"argv": ["flatpak", "uninstall", "--unused"], "dry_run_argv": ["flatpak", "uninstall", "--unused", "--dry-run"], "risk": 2},
  "system.status": {"argv": ["systemctl", "status", "{unit}", "--no-pager"], "risk": 0}
}

({pkg} resolvido por utils/platform.py: apt/dnf/zypper.)
T2.3 — Criar agent/policy_engine.py

class PolicyEngine:
    def classify(self, argv: list[str], requires_admin: bool) -> RiskLevel
    def evaluate_step(self, step: ActionStep) -> ActionStep   # sobrescreve risk/approval
    def evaluate_plan(self, plan: ActionPlan) -> ActionPlan   # marca steps BLOCKED

Regras:
Casa deny_patterns → BLOCKED.
requires_admin=True → só prossegue se casar com admin_actions.json (mapeia para tool="admin.run_action" + action_id); senão BLOCKED.
argv com escrita fora da home → eleva para CRITICAL.
Define approval: risk 0→click, 1→diff, 2→polkit, 3→blocked (com opção de revisão manual).
T2.4 — Criar agent/path_guard.py

class PathGuard:
    def can_read(self, path: str) -> bool
    def can_write(self, path: str) -> bool

Denylist padrão de leitura: ~/.ssh, ~/.gnupg, ~/.aws, ~/.kube, ~/.docker, ~/.netrc, ~/.pypirc, ~/.npmrc, **/.env, ~/.git-credentials, ~/.bash_history, ~/.zsh_history, ~/.local/share/keyrings, ~/.config/gcloud.
Denylist padrão de escrita: ~/.bashrc, ~/.zshrc, ~/.profile, ~/.config/autostart/**, ~/.config/systemd/user/**, ~/.ssh/**.
Raízes permitidas configuráveis (default: ~/Documents, ~/Projects, ~/Downloads, ~/scripts).
Resolver symlinks (os.path.realpath) antes de validar (anti-bypass).
Critérios de aceite:
PolicyEngine.classify(["rm","-rf","/"]) → BLOCKED; ["ls","-la"] → READ_ONLY.
PathGuard.can_read("~/.ssh/id_rsa") → False mesmo via symlink.
🟠 FASE 3 — Registro de Ferramentas e Executores
T3.1 — Criar agent/tool_registry.py
class ToolRegistry:
    def register(self, name: str, handler, schema: dict)
    async def invoke(self, name: str, params: dict, ctx: ExecContext) -> ToolResult

Tools a registrar:
Leitura: fs.list_directory, fs.metadata, fs.read_file, fs.search_text, fs.disk_usage
Escrita: fs.write_staged_file, fs.propose_edit, fs.create_directory, fs.move_to_trash
Shell: shell.run, shell.dry_run
Admin: admin.run_action
T3.2 — Criar agent/shell_tools.py
run_argv(argv, cwd, timeout, env_sanitized) usando asyncio.create_subprocess_exec (nunca shell=True, nunca sh -c).
Truncar saída em 10.000 chars (truncated=True).
Env sanitizado: remover variáveis com tokens/secrets (*_TOKEN, *_KEY, AWS_*).
Timeout obrigatório → ToolResult(status="timeout").
T3.3 — Criar agent/fs_tools.py
fs.read_file: valida PathGuard.can_read; limite de bytes (config, default 20.000); passa pelo Redactor (T3.5).
fs.write_staged_file: grava em ~/.cache/zashterminal/ai-staging/<plan_id>/<nome>; nunca no destino final.
fs.propose_edit: gera diff (difflib.unified_diff) entre arquivo atual e versão proposta; retorna diff para a UI.
fs.apply_staged: (chamado só após aprovação na UI) copia staging→destino com backup automático via utils/backup.py.
T3.4 — Criar agent/admin_tools.py
admin.run_action(action_id, params, dry_run):
Valida action_id + params contra admin_actions.json (regex por parâmetro).
Monta argv final a partir do template.
Executa via pkexec /usr/lib/zashterminal/zashterminal-admin-helper --action <id> --args <json> [--dry-run] (helper da Fase 6). Fallback WSL: sudo -n com aviso de experimental.
T3.5 — Criar agent/redactor.py
Regex de redação: chaves AWS (AKIA[0-9A-Z]{16}), blocos -----BEGIN *PRIVATE KEY-----, Bearer \w+, password=..., token=..., connection strings.
Retorna (texto_redigido, contagem).
Reutilizar/estender utils/security.py se houver função equivalente.
Critérios de aceite:
shell.run com ["sh","-c","ls"] → denied.
fs.read_file em .env → denied; em ~/Projects/x.py com token → conteúdo redigido + secrets_redacted>0.
